# PA 發音認證互動學習單

蕭博士 SoR 美語 PA 發音認證的單檔互動學習單（`index.html`）。

- **PA 進階認證・8800 音**：2026 年 7～12 月 CVC 考題 10 題，注音積木、示範音檔、節拍跟讀、模擬錄音錄影、正式錄影（檔名 姓名_01～姓名_10）與劃記自評
- **歷屆考題**：2026 年 1～6 月題組（奕安老師示範音檔）
- **PA 初階認證 280 音**：140 音、280 音雙語音標表，蕭博士示範音檔（小8、藍方老師剪輯提供），節拍跟讀與 1 分 30 秒錄影（檔名 姓名_140音、姓名_280音）

官方公告與報名：https://milinguall.com/news_2024.aspx?id=271

錄音錄影需要以 https 開啟（GitHub Pages 即可），並允許瀏覽器使用鏡頭與麥克風。
